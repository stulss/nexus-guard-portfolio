랜섬웨어 확산 등 심각한 침해 국면에서 관제관이 [비상 호스트 격리] 버튼을 누르면 모든 인바운드/아웃바운드 패킷이 즉각 차단됩니다.

이때 관리 루프백(`127.0.0.1`, `localhost`, `::1`)은 영구 화이트리스트로 보호되므로, 네트워크를 차단해도 관제 콘솔 UI가 멈추거나 시스템이 영구 벽돌(Bricked) 상태가 되지 않고 언제든 1초 만에 안전하게 복원할 수 있습니다.

📝 자기소개서 [문항 1] 문제 해결 경험 (STAR 기법)

"오탐과 의존성을 제거한 무결점 클린 슬레이트(Clean Slate) 보안 관제 솔루션 구축"

Situation (상황):
기존의 많은 보안 관제 도구와 학습용 프로젝트들은 최초 기동 시 사전에 주입된 더미 공격자 데이터나 임의의 감점 점수가 잔류하여, 실제 새 PC나 운영 환경에 설치했을 때 '시스템이 왜 시작부터 위험 상태인가?'라는 오탐과 사용자 불신을 초래했습니다. 또한 소스코드 기반 실행 방식은 파이썬 인터프리터 및 다양한 그래픽 라이브러리 종속성으로 인해 비개발자나 다른 환경에서 즉시 구동하기 어려운 장벽이 있었습니다.

Task (과제):
새로운 PC에 처음 설치했을 때 어떠한 잔류 데이터도 없이 '100점 만점 / 활성 위협 0건'의 완벽한 신규 상태(Clean Slate)를 보장하는 독립형 네이티브 관제 소프트웨어를 완성하고, 파이썬이 없는 환경에서도 더블클릭 한 번으로 1초 만에 구동 가능한 상용화 수준의 패키징을 달성해야 했습니다.

Action (행동):
첫째, `FirewallRuleManager`, `FileIntegrityMonitor`, `ControlCenter` 등 코어 모듈의 인스턴스 초기화 로직을 전면 정비하여 외부 이벤트가 유입되기 전까지는 차단 목록 0건, 위협 점수 0점(종합 안전도 100점)을 유지하도록 상태 머신을 격리하고 `test_clean_slate.py`로 자동 검증했습니다.
둘째, SentinelOne과 GlassWire의 직관적 UX를 벤치마킹하여 360도 레이더에 4대 인프라 범례를 명시하고 비전문가도 1초 만에 파악할 수 있는 쉬운 한글 종합 판정 배너와 WCAG 2.x AA 고대비 가이드라인을 적용했습니다.
셋째, `PyInstaller` 기반 17.5MB 단일 실행 파일(`NexusGuard.exe`)을 패키징하고 Git 태그 푸시 시 클라우드에서 70개 테스트를 통과해야만 배포 파일이 등록되는 GitHub Actions CI/CD를 완성했습니다.

Result (결과):

📝 자기소개서 [문항 2] 능동 방어 및 이기종 인프라 연동 역량

"단순 탐지를 넘어 즉각 격리와 1초 복구를 실현한 차세대 Active Defense 체계"

전통적인 보안 체계는 방화벽에 기록된 로그를 사후에 분석하는 수동적 방식에 머물러 있어, 웹쉘 업로드나 기밀 파일(`.env`) 탈취와 같은 고속 침해 행위를 실시간으로 막아내지 못했습니다.

저는 시스템 공격 표면에 공격자가 침투할 만한 미끼 경로(`/.env`, `/.git`, `/admin.php`)를 전략적으로 배치하는 디코이(Decoy Trap) 기술을 구현했습니다. 공격자가 해당 경로에 단 1바이트라도 프로빙하는 즉시 0.1초 만에 커널 방화벽(`netsh advfirewall`)을 호출하여 해당 IP를 403 차단하고, 이 이벤트를 pfSense, Graylog(GELF UDP 12201), Wazuh(FIM SHA-256), n8n SOAR로 동시 전파하도록 설계했습니다.
더 나아가 시연 후 환경을 단 1초 만에 원래 상태로 리셋하는 `demo_runner.py --cleanup` 롤백 엔진을 구축하여, 운영 안정성과 유지보수성을 극대화했습니다.
